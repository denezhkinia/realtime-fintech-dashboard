# Realtime Fintech Dashboard

Angular 19 live market dashboard with an AssemblyScript Wasm producer in a Web Worker.

## Setup

```bash
pnpm install
```

## Develop

```bash
pnpm nx serve dashboard
```

## Test

```bash
pnpm nx run-many -t test
```

## Build

```bash
pnpm nx build dashboard
```

## Docker (local / repro)

```bash
docker compose up --build
```
